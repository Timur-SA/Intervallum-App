Репозиторий в рамках проекта Intervallum

Для работы требуется Intervallum-Core

## Быстрый старт
Создайте новую папку и установите скрипт для деплоя:
```sh
mkdir Intervallum
cd Intervallum
curl -sSL https://github.com/Timur-SA/Intervallum-App/releases/latest/download/deploy.sh -o deploy.sh
chmod +x deploy.sh
```

Запустите его:
```sh
SITE=enter.your.domain ./deploy.sh
```

После завершения скрипта нужно настроить роутинг.
Пример для Caddy:
```yml
enter.your.domain {
    handle /v2/* {
        reverse_proxy localhost:8000
    }

    handle {
        reverse_proxy localhost:3000
    }
}
```

## Функционал
В рамках хакатона реализована Базовая версия:
- Персональная тренировка (изучение новых тем, а также повторение старых с персонализированным подбором интервалов)
- Карта тем для подготовки
- Теоретический материал
- Дополнительные стимулы (например, Daily streak)
- Профиль, настройки и прочее

Остальной функционал планируется уже для Полной версии, которая будет распространятся на платной основе для индивидуальных учеников или целых школ (с дополнительными групповыми функциями: лидерборд, дуэли, экзамены, статистика по классу)
